# 战雷圆桌工程 · 使用说明

一个本地小工具，把《战争雷霆》玩家常做的三件事合到一起。**全离线，不联网，不上传任何数据。**

```
双击  启动圆桌工程.bat  →  浏览器自动打开 http://127.0.0.1:8788
关掉那个黑色窗口 = 关掉工具
```

## 三大母功能

| 母功能 | 做什么 | 需要额外装什么 |
|---|---|---|
| **语音包工程** | 从你游戏里解包原版乘员语音 → 换声 / 造声 → 加无线电效果 → 打包成 bank → 装进游戏 | 可选：SDV 换声、TTS 造声（两个大扩展） |
| **战雷头像提取** | 从你游戏里解包全部头像 / 头像框 / 资料页头图，带中文名和缩略图 | 不需要 |

点进「语音包工程」时，会先做一次**本机环境检测**，告诉你缺什么、去哪下、装完放哪。

## 会用到什么

**必须**：Python 3.10 或更高版本
官网 <https://www.python.org/downloads/>，安装时**务必勾选 "Add python.exe to PATH"**。
不需要 pip 装任何东西 —— 后端只用标准库。

**可选**（不装也能用大部分功能）：

| 工具 | 用在哪 | 体积 |
|---|---|---|
| SDV 换声（SeedVC） | 语音包·换声 | 约 8.7 GB，要 4 GB 以上显存 |
| TTS 造声（IndexTTS2） | 语音包·造声 | 约 18.7 GB，要 6~8 GB 显存 |
| FMOD 模组包（Gaijin 官方） | 语音包·打包成 bank | 约 1.9 GB |

**两个语音扩展不随本包分发** —— 它们体积很大且各有自己的许可，请在检测弹窗里点「下载并安装」，
走官方渠道（GitHub / HuggingFace / 魔搭）获取。装完把目录填进「设置」里的对应路径即可。

## 第一次用

1. 双击 `启动圆桌工程.bat`；
2. 浏览器打开后点右上角 **设置**，确认「游戏根目录」指向你的战雷安装位置
   （里面应该有 `sound` 文件夹）。找不到会自动搜。
3. 回到首页，点「语音包工程」→ ① 下载乘员组语音，挑一个语种点一下才会开始解包。

## 目录说明

```
战雷圆桌工程\
    启动圆桌工程.bat        ← 双击这个
    server.py               ← 后端（纯 Python 标准库）
    web\                    ← 网页
    核心\                    ← 引擎，平时不用碰
        vgmstream\               解包游戏语音 / 头像包
        tts_batch.py             TTS 批处理驱动
        提取战雷头像.py           头像解包
        头像中文名.json           头像中文名表
    头像\                    ← 解包出来的头像放这儿
    config.json              ← 路径配置（首次运行自动生成）
    _cache\                  ← 缩略图缓存，可以随时删
```
