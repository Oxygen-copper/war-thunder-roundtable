# 战雷圆桌工程

一个本地网站，把**战雷语音包**的制作流程从头到尾合到一起。
全离线，不联网，不上传任何东西 —— 关掉黑色窗口就等于关掉它。

## 怎么开

双击 **`启动圆桌工程.bat`** → 浏览器自动打开 `http://127.0.0.1:8788`（端口被占会自动往后找）。

只有一个要求：

1. **Python 3.10+**（安装时勾选 *Add python.exe to PATH*）。不需要 pip 装任何东西。

## 目录长这样

```
战雷圆桌工程\
    启动圆桌工程.bat        ← 双击这个
    server.py               ← 后端（纯 Python 标准库）
    web\                    ← 前端页面
    核心\                    ← 引擎，平时不用碰
        vgmstream\               游戏 bank 解包
        tts_batch.py             TTS 批处理驱动
        提取战雷头像.py           头像解包
        头像中文名.json           头像中文名表
    头像\                    ← 解包出来的头像放这儿
    语音\
        原版\                    从游戏里解出来的原版乘员语音
        工程\                    每个语音包的工程
        成品\                    打包好的成品（bank / zip）
        参考音色\                5~15 秒的参考音频放这儿
    _cache\                 缓存（可以随时删）
    config.json             路径配置（自动生成）
```

# 语音包工程

界面上是**三层**，一层一层往里点：

```
首页
 └ 语音包工程
    ├ ① 下载乘员组语音 ── 陆战乘员组 / 海战乘员组 / 空战告警语音 / 通用战场播报
    │                        └ 范围：只看八大系 / 全部
    ├ ② SDV换声 / TTS造声 ── 左右两半，点哪半就高亮哪半并切到对应界面
    └ ③ 安装 / 打包
```

三个母选项横向排在顶上，点哪个进哪个；② 里再左右二选一。

### ① 下载乘员组语音

直接读你自己游戏里的 bank，用 vgmstream 一次性把里面**所有命名音频流**解成 wav。
三个子项目各管一摊：

| 子项目 | 对应 bank | 覆盖 |
|---|---|---|
| **陆战乘员组** | `_crew_dialogs_ground_*` | 35 种语言/变体，其中英美苏德日中六国各**多一套"备用录音"** |
| **海战乘员组** | `_crew_dialogs_naval_*` | 7 种 |
| **空战告警语音** | `aircraft_gui`（VWS，全语种合一） | 1，约 320 条 |
| **通用战场播报** | `_crew_dialogs_common_*` | 17 种，基地占领 / 任务开始 / 胜利播报、通用战术口令 |

> 关于"备用录音"：`_crew_dialogs_ground_sm_XX` 这个命名容易误会成舰船，
> 实测里面**全是陆战乘员台词**（1318 条里没有一条含 ship / torpedo / rudder / submarine），
> 和普通那套有 1244 条同名但**时长全部不同**，也就是同一批台词的另一次录音；
> 普通那套多出 `chief_battle_*`（指挥部战况播报）。`sm` 这个缩写的官方含义暂未确认。

勾上「只看八大系」就只剩英（含澳、南非变体）、美、苏、德、中、日、法、以；
取消勾选才会看到波兰、捷克、匈牙利、塞尔维亚、韩、泰、土、越、葡、西、意、
芬兰、荷兰、瑞典、挪威、立陶宛、加利西亚、印地、阿拉伯这些小系。

### ② SDV换声 / TTS造声

顶上左右两块，点左边进 SDV、点右边进 TTS，当前那块高亮。

**SDV 换声**（把已有的人声换成目标音色）

| 控件 | 说明 |
|---|---|
| 迭代步数 | 滑块 30~100。步数越高音质越好，代价是速度下降、显存占用上升 |
| 输出音调 | 滑块 ±12 半音，成品整体调亮或调沉（时长不变） |
| 启用 F0 | 鼠标停 0.8 秒会弹出说明：开着会跟着源音频的音高走，唱歌/翻唱/带起伏的台词必须开；关掉更平但更快更省显存 |

约 2.7 秒/条；中断后重跑自动接着来。下方还有**无线电效果**（旧式电台音质，四个预设）。

**TTS 造声**（从文字生成语音）

从文字直接生成语音（IndexTTS2），可以再指定一条**情绪参考**音频。
手里没有现成素材、需要补游戏里没有的台词时用它。

> **怎么选**：SeedVC 是"换声"，必须有人声素材；TTS 是"造声"，只要有文字。
> 做整套乘员包通常是 **SDV 打底 + TTS 补缺口**。

两种输入方式：

1. **手动输入** —— 一行一句，输出 `001.wav`、`002.wav`…
2. **读取 TXT** —— 上传稿子文件，按 `WT0001-xxx WT0002-yyy` 的格式批量朗读。
   **唯一的句子分割点是每句开头的 `WT` + 四位数字**，换行和空格都算同一句的一部分；
   生成的文件名就是 `WT0001.wav`。上传后会先显示解析预览（条数 + 前 200 条）。

同样有**输出音调**滑块，生成完逐条移调（时长不变）。整批只加载一次模型，条数越多越划算。

同一个页面下半部分是**无线电效果**：带通 + 中频凸起 + 软削波 + 数码量化 + 带内底噪 + 静噪咔哒，
四个预设、约 16 条/秒，纯本地 DSP。

### ③ 安装与打包

- **① 从我的音频素材打包**：给一个装着处理好的 wav 的文件夹，工具自动认出这是哪套乘员语音、把文件名对齐成官方工程的结构，再交给 **FMOD 命令行构建器**（`fmodstudiocl.exe -build`）构建 bank。构建完会问一句要不要顺手装进游戏。
- **② 装别人打好的 zip**：手里已经是 bank 或打包好的 zip，走这条，直接进 `<游戏>\sound\mod`。

装的时候如果 `sound\mod` 还不存在，工具会问一次要不要自动建好、并把 `config.blk` 里的 mod 开关打开（改之前会备份原文件）。

装完重启游戏生效。下面「已经安装的语音包」按语种自动分组，能看到大小、能一键移除，也能直接打开那个文件夹。

## 给别人用

打包整个 `战雷圆桌工程` 文件夹即可，但**删掉这些**再发：

| 删 | 原因 |
|---|---|
| `_cache\` | 缩略图缓存，本机生成 |
| `_import_tmp\` | 临时目录 |
| `config.json` | 里面是本机路径，对方首次运行会自动搜 |
| `语音\原版\`、`语音\工程\` | 体积大且是私人素材，看你想不想带 |

对方只需要装 Python 3.10+，双击 `启动圆桌工程.bat` 就行。
