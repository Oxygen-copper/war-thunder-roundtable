# 战雷圆桌工程

《战争雷霆》自定义语音包的一站式制作工具：**从你自己的游戏里提取原素材 → 换声 / 造声 → 无线电效果 → 打包成 bank → 装回游戏**，全程在同一个界面里。

做这个的起因很简单：想做一套语音包，得在 vgmstream、SeedVC、IndexTTS、FMOD 之间来回倒腾，每步的教程还散在不同地方、不少是英文的。这个工具把这些串成了一条线。

> 本工具**只读你本机的游戏文件**，不上传任何数据、不联网、不改动游戏本体。

## 能做什么

- **下载原版乘员语音** —— 从你自己的游戏里解包，陆战 / 海战 / 空战告警 / 通用播报，支持游戏里的全部语种
- **SDV 换声** —— 换音色不换内容，批量转换，可调迭代步数与输出音调
- **TTS 造声** —— 从文字直接生成语音，支持 txt 批量（`WT0001-台词` 格式），可指定情绪参考
- **无线电效果** —— 批量给语音加上无线电质感，几档预设
- **打包与安装** —— 自动按官方工程归位素材、调用 FMOD 构建 bank、装进 `sound\mod`，装前自动备份
- **战雷头像提取** —— 头像 / 头像框 / 资料页头图，带中文名和缩略图

## 环境要求

- Windows
- **Python 3.10 或更高**，安装时勾选 “Add python.exe to PATH”
- 《战争雷霆》本体（素材来源，工具不提供游戏资源）
- 可选扩展：见下面「要另外装的东西」

## 快速开始

1. 下载并解压
2. 双击 `启动圆桌工程.bat`
3. 等几秒，浏览器会自动打开界面（默认 `http://127.0.0.1:8788`）

### 首次启动会自动提取素材

第一次运行时，工具会检测你机器上有没有从游戏里解出来的素材。没有的话会弹一个窗口问你要不要现在提取，确认后它自动做两件事：

- 从 `游戏\ui\images.vromfs.bin` 解出**全部头像 / 头像框 / 资料页头图**（约 10 MB）
- 从 `游戏\sound\` 里解出**陆战八大系的原版乘员语音**（约 130 MB）

这些素材**保存在你本机**，只在打包时用到，不会上传、也不会随本工具分发。

游戏路径一般能自动探测到；探测不到就在右上角「设置」里手动填。

## 要另外装的东西

这三样各自有自己的许可、体积也不小，所以**不随本工具分发**，工具里提供了官方渠道和「放哪里」的说明。

| 组件 | 用途 | 大约 |
|---|---|---|
| **SeedVC (SDV)** | 换声 | 8.7 GB |
| **IndexTTS2 (TTS)** | 造声 | 18.7 GB |
| **FMOD Studio + 战雷模组工具包** | 打包成 `.bank` | 2 GB |

装完回到界面点一次「刷新」，检测就会变成已就位。也可以放到别处，然后在「设置」里把路径指过去。

**只想装别人做好的语音包**的话，上面三个都不用装 —— 拿到 zip 直接上传安装即可。

## 目录结构

```
启动圆桌工程.bat      启动入口
server.py             本地服务（标准库，无第三方依赖）
web/                  界面：index.html / app.js / style.css
核心/                 提取脚本、转换工具、知识库
语音/                 原版素材、工程、成品、参考音色（首次启动后生成）
头像/                 提取出来的头像（首次启动后生成）
扩展/                 SDV / TTS 放这里（可选）
config.json           本机路径配置（自动生成，不随仓库分发）
```
