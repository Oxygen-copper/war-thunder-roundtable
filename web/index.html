范围

SDV · SeedVC 换声

把已经有的人声换成目标音色。输出保留原本的语气和节奏，只换声线 —— 做整套乘员包的主力。

替换声音时每一个项迭代的步数，越高质量越好，代价是相对下降的速度和占用运存的上升。

正数调高、负数调低，单位是半音（±12 = 一个八度）。用来把成品整体调亮或调沉。

约 2.7 秒/条（RTX 5060）；中断后重跑会自动接着来。

附加 · 无线电效果

换完声之后，顺手把音质做成旧式电台听感（带通 + 中频凸起 + 软削波 + 数码量化 + 带内底噪 + 静噪咔哒）。约 16 条/秒，纯本地 DSP。

TTS · IndexTTS2 造声

从文字直接生成语音。手里没有现成素材、需要补游戏里没收录的台词时用它。

SDV 和 TTS 怎么选？
SDV（换声）：必须有人声素材，音色和语气都自然，适合大批量。
TTS（造声）：只要给文字就行，能补游戏里根本不存在的内容，但语气和停顿要自己调，适合短句。
一般做法：SDV 打底 + TTS 补缺口。
还没选

格式：每句以 WT + 四位数字开头，例如 WT0001-Driver, move out! WT0002-Target destroyed!
WT#### 是唯一的分割点 —— 换行和其他空格都算同一句里的一部分。 生成的文件名就是 WT0001.wav 这样。

生成完之后逐条移调（时长不变）。正数调高、负数调低。

整批只加载一次模型，所以条数越多越划算。

打包 / 安装

两条路：自己的音频素材交给它，自动归位、构建 bank，做完问你要不要顺手装进游戏；别人打好的 zip 直接上传装。

① 从我的音频素材打包

里面放 wav / mp3。文件夹叫中文、分类混在一起、多套语言堆在一个目录里，都能认。 构建完会问你要不要顺手装进游戏。

② 装别人打好的 zip

别人发你一个打包好的语音包 zip 时用它。不用解压 —— 工具自己解开、找到里面的 bank， 装进 游戏\sound\mod，重启游戏生效。装之前会自动备份被覆盖的文件。
